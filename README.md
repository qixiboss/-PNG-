# 跑步数据叠加器 - Running Data Overlay Tool

一个专业的运动数据处理工具集合，用于处理跑步数据图片，包括批量裁切、背景移除和数据叠加功能。

## 📋 功能特点

### Step 1: 批量图片裁切 (Batch Crop)
- 一键批量裁切多张图片为相同尺寸
- 提高图片处理效率
- 支持自定义裁切区域

### Step 2: 黑底转透明 (Background Removal)
- 批量将黑色背景转换为透明背景
- 支持颜色选取功能，可选择要移除的目标颜色
- 导出为PNG格式，保留透明度信息

### Step 3: 跑步数据叠加 (Data Overlay)
- 将跑步数据叠加到视频或图片上
- 支持多图层编辑，可添加多个数据图片
- 支持拖拽调整位置、缩放大小
- 支持选中图层聚焦效果
- 支持滚轮缩放选定图层

## 📹 如何使用

1. 首先使用 **批量图片裁切** 工具将原始图片裁切为相同尺寸
2. 然后使用 **黑底转透明** 工具将裁切后的图片背景转换为透明
3. 最后使用 **跑步数据叠加** 工具将透明数据图片叠加到底图上

### 演示视频

打开 `index.html` 页面，即可观看完整的演示视频。

## 📖 使用说明

### 批量图片裁切

1. 点击 "选择图片" 按钮，选择要裁切的图片
2. 拖拽调整裁切区域
3. 点击 "批量裁切" 按钮，等待处理完成
4. 选择输出文件夹，导出裁切后的图片

### 黑底转透明

1. 点击 "选择图片" 按钮，选择要处理的图片
2. 使用颜色选取工具选择要移除的背景颜色
3. 点击 "开始处理" 按钮，等待处理完成
4. 选择输出文件夹，导出透明背景图片

### 跑步数据叠加

1. 点击 "选择底图" 按钮，选择底图图片
2. 点击 "批量导入PNG" 按钮，选择要叠加的数据图片
3. 拖拽调整数据图片的位置
4. 选中图层后可使用滚轮缩放大小
5. 点击 "导出图片" 按钮，保存最终效果
